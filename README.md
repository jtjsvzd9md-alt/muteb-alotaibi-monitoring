# مشروع: نظام متابعة متكامل

**المالك:** متعب العتيبي

## نظرة عامة

هذا المستودع يحتوي على قالب احترافي ومُبدع لنظام متابعة متكامل موجه للمؤسسات. يغطي:

- المتابعة للأرقام العالمية (أسعار صرف، إحصاءات مستخدمين، مؤشرات أداء)
- مراقبة نماذج الذكاء الاصطناعي الاحترافية (مثل GPT-6-Astra)
- المتابعة المحاسبية (مطابقة دفاتر، فواتير متأخرة)
- متابعة أمين الخزينة والسياسات المالية

الهدف: تزويد فرق العمليات، البيانات، والمالية بأداة تهيئة قابلة للتنفيذ لربط مقاييسهم مع قنوات التنبيه والتصعيد.

## المميزات

- تنسيق YAML واضح وقابل للتوسع (`monitoring-config.yaml`)
- إعدادات عتبات مرنة وتنبيهات متعددة القنوات (Slack، email، PagerDuty)
- إعدادات خاصة بمراقبة أداء ونزاهة نماذج الذكاء الاصطناعي
- سياسات تصعيد وصلاحيات أمين الخزينة

## كيفية الاستخدام

1. افتح `monitoring-config.yaml` وعدِّل مصادر البيانات (APIs، قواعد البيانات، endpoints) حسب بيئتك.
2. اربط النظام بمنصة المراقبة لديك (Prometheus/Grafana أو سكربت يجلب المقاييس ويُدفع إلى Pushgateway).
3. حدِّد قنوات التنبيه في قسم `alerts.default_channels` (أمثلة مذكورة داخل الملف).
4. ضع الإعدادات في بيئتك، ثم اختبر التنبيهات والـ runbooks قبل التشغيل الإنتاجي.
